# چرتکه — نسخه ۱.۲.۱ (پیش‌نمایش)

## تغییرات این مرحله
- اصلاح اجرای فرم ثبت تراکنش؛ کد تقویم شمسی دیگر داخل رویداد ثبت تکرار نمی‌شود.
- تهیه خودکار یک کپی خام از پایگاه داده پیش از مهاجرت نسخه‌های قدیمی‌تر.
- افزودن گزینه «ثبت فاکتور با عکس» به‌صورت قفل‌شده؛ هیچ عکس یا داده‌ای پردازش یا ذخیره نمی‌شود.
- حفظ تقویم شمسی، گزارش سه‌سطحی، ثبت مقدار/واحد و پشتیبان‌گیری دستی.

## نکات مهم
- اطلاعات در LocalStorage همان مرورگر/دستگاه ذخیره می‌شوند و همگام‌سازی ابری وجود ندارد.
- قبل از نصب، همچنان از داخل نسخه فعلی فایل پشتیبان بگیرید.
- نسخه جدید را ابتدا در یک مرورگر آزمایشی با کپی پشتیبان بررسی کنید؛ هنوز روی داده واقعی کاربر آزمایش نشده است.
