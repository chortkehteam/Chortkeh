# چرتکه

برنامه مدیریت درآمد و هزینه خانواده.

## نسخه 1.1
- افزودن مهاجرت ساختار ذخیره‌سازی از نسخه 1 به نسخه 2 بدون حذف تراکنش‌ها.
- جلوگیری از بازنشانی خاموش اطلاعات در صورت خرابی داده یا مواجهه با نسخه جدیدتر.
- غیرفعال کردن ثبت تراکنش هنگام خطای ساختار داده برای جلوگیری از بازنویسی ناخواسته.
- پشتیبان‌گیری از داده ذخیره‌شده و نگهداری نسخه قبلی پیش از بازیابی.
- پشتیبانی از بازیابی فایل پشتیبان نسخه 1 و 2.

## نکته مهم
این نسخه همچنان از LocalStorage همان مرورگر/دستگاه استفاده می‌کند. پاک‌کردن داده‌های مرورگر یا تغییر دستگاه می‌تواند اطلاعات را از دسترس خارج کند؛ بنابراین باید نسخه پشتیبان منظم تهیه شود. همگام‌سازی ابری و پایگاه داده مستقل هنوز پیاده‌سازی نشده‌اند.
